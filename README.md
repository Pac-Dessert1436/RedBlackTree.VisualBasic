# RedBlackTree.VisualBasic

A feature-complete VB.NET implementation of the Red-Black Tree data structure. Supports insertion, deletion, search, and custom comparers.

This repository is an NUnit project with a full unit test suite, written to verify that the Red-Black Tree is production-ready. _Still, it was built under the pressure of my exam prep — see [A Note From the Author](#a-note-from-the-author) for the full story._

**All tests pass.** To use this data structure in a production VB.NET project, simply copy `RedBlackTree.vb` into your solution.

## Prerequisites

- [.NET SDK 10.0](https://dotnet.microsoft.com/download) or higher

## Installation & Usage

Clone the repository:
```bash
git clone https://github.com/Pac-Dessert1436/RedBlackTree.VisualBasic.git
```

Then copy `RedBlackTree.vb` into your own VB.NET project.

To run the tests:
```bash
cd RedBlackTree.VisualBasic
dotnet test
```
